# Gotcha ガチャ

A 3D Japanese gachapon machine full of affirmations. Turn the handle, a capsule rolls out, tap it to open your message.

- **web/** — Three.js single page (`web/index.html`). Open it directly or serve the folder.
- **ios/** — SwiftUI + SceneKit app.

Messages come from a shuffle deck: you see all 9 before any repeats.
